    Software Engineering¶

    Welcome to the Software Engineering section of my handbook. It is grouped the way the work is: the foundations of code, how systems are designed, how they talk and stay secure, how teams deliver them, how engineers grow, and the tools along the way.

    Foundations¶

    • Fundamentals - Paradigms, code unit hierarchy, and formal languages.
    • Data Structures & Algorithms - Big-O, core data structures, and common algorithmic patterns.
    • Concurrency - Concurrency vs parallelism, shared mutable state, primitives, and hazards.
    • Error Handling - Anticipate, detect, and report failures so they fail safely.
    • Debugging - Six famous engineers' debugging habits, fact-checked, and one workflow from repro to regression test.
    • Styles - My naming and code conventions for folders, files, and components.

    Design & Architecture¶

    • Design Principles - SOLID, DRY/KISS/YAGNI, and clean code habits.
    • Architecture - Layers, code organization, system patterns, and system design building blocks.
    • System Design Notes - Design patterns, API types and protocols, auth methods, SSH, deployment strategies, and retry and resilience, built from seven cited posts.
    • Tech Stacks - Languages, databases, and classic stack combinations.

    Networking, APIs & Security¶

    • Networking - TCP/IP, TCP vs UDP, HTTP methods, and what happens when you open a URL.
    • APIs - API styles, status codes, idempotency, versioning, and pagination.
    • Security - The CIA triad, authentication vs authorization, OWASP risks, and crypto basics.

    Process & Delivery¶

    • Philosophies & Methodologies - Lean, Agile, DevOps, and how Waterfall, V-Model, Scrum, Kanban, SAFe, XP, Shape Up, RUP, Iterative, Hybrid, and Spiral work, with diagrams.
    • Lifecycle - SDLC phases, roles, environments, testing, CI/CD, and version control.
    • Work Items & Templates - Epics, stories, tasks, bugs, change requests, incidents, sprints, milestones, issues, PRs, and commit messages: what they are, where they sit in the SDLC, and templates.
    • SDLC Documents & Templates - BRD, SRS, design doc, ADR, test plan, changelog, release notes, runbook, plus kickoff, rehearsal, and go / no-go, organized by phase.
    • Git: Merge vs Rebase - Branch mechanics, conflicts, and the daily workflow.
    • Code Review - Reading a diff, reviewing a PR, and AI-assisted review.
    • Delivery & Productivity Metrics - DORA for outsourcing projects, SPACE, cost per outcome, and how large companies measure, computed from work-item fields.

    Career & Learning¶

    • Becoming Senior - What seniority means: technical skill anchored in business meaning.
    • Senior Curriculum - A self-study path of books, courses, postmortems, papers, and drills.
    • Study Guide - How to learn a new technology efficiently.
    • The Architecture Bookshelf - A map of the software-architecture literature by subfield, annotated and cross-linked.
    • Posts - My posts on software engineering.

    Tools & Tips¶

    • Tools - Tool selection, Python workflows, code checks, local services, and design tools.
    • Tips - Pair-coding with AI, testing habits, and custom commands.
    • Machine Setup - Getting a fresh Linux box ready for development.
    • Running a Server - Sizing a VPS, the USE method, disk and inode exhaustion, and triage runbooks.
    • CI/CD Platforms - GitLab CI, GitHub Actions, Azure Pipelines, Jenkins, and Vercel: config files, connection mechanisms, secrets, and runner resources.
    • Frontend Toolchain - A 2026 frontend stack: six dropped tools, what replaced them, and why.
    • Linux Commands - Command reference: files, network, processes, Git, Docker, and Kubernetes.
    • tmux Cheatsheet - Sessions, panes, and windows for resilient remote work.

    • Terms - 800+ software, SDLC, and operations terms grouped by domain, each linked to where the handbook explains it.
